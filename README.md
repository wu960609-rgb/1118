## 問題回答

1. **為何文字人數要轉成數字？**
   在 Python 中，原始資料 `people = "4"` 是字串（`str`）型別，不能直接進行數學除法運算（若直接用總額除以字串會發生 `TypeError` 錯誤）。因此必須透過 `int(people)` 將其轉換為整數（`int`），才能正確計算出每人分攤的費用。

2. **為何先扣折價券再計算服務費時，第一組總額會變成 1,210 元？**
   原本的程式邏輯是先用原始餐費 $1,200$ 元計算 $10\%$ 服務費（$1,200 \times 0.10 = 120$ 元），最後才扣除 $100$ 元折價券，因此總額為 $1,200 + 120 - 100 = 1,220$ 元。
   若改為「先扣折價券再計算服務費」，計算服務費的基準金額會先變成 $1,200 - 100 = 1,100$ 元，此時的 $10\%$ 服務費為 $1,100 \times 0.10 = 110$ 元，加上折價後的餐費，應付總額就會變成 $1,100 + 110 = 1,210$ 元。
